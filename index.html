bat

cat

Prints a file the way your editor shows it.

$ cat server.ts

import { serve } from "bun";
import { app } from "./app";

const port = Number(process.env.PORT ?? 3000);

serve({ port, fetch: app });
console.log(`listening on :${port}`);
$ bat server.ts
───┬──────────────────────────────────────────────────
 1 │   import { serve } from "bun";
 2 │ + import { app } from "./app";
 3 │
 4 │ ~ const port = Number(process.env.PORT ?? 3000);
 5 │
 6 │ + serve({ port, fetch: app });
 7 │   console.log(`listening on :${port}`);
↗

tldr

man

Examples first. The manual never.

$ tldr tar

Extract an archive:
  tar xf archive.tar

Create a gzipped archive:
  tar czf out.tar.gz dir/

List what's inside:
  tar tvf archive.tar
